# Petroleum Traps Segmentation

Проект для сегментации структурных ловушек по структурным картам сейсмических горизонтов на основе архитектуры **U-Net++** с использованием **PyTorch**.

## 🎯 Описание

Проект предоставляет полный пайплайн для обучения, оценки и визуализации моделей сегментации структурных ловушек по структурным картам сейсмических горизонтов. Включает в себя продвинутые техники мониторинга градиентов, защиты от утечки данных и детектирования аномалий.

## ✨ Особенности

- **Архитектура**: U-Net++ с поддержкой различных encoder'ов (ResNet34)
- **Источники данных**: 
  - `cps_tiles`: PNG файлы из CPS гридов с каналами RGB, depth, isolines [+ faults опционально]
- **Мониторинг**: Трекинг градиентов (взрыв/затухание), анализ аномалий в лоссах
- **Защита от leakage**: Утилиты для проверки пересечений между train/val/test
- **Гибкость**: Поддержка режимов с разломами и без, кастомные лоссы и метрики
- **Тестирование**: Полное покрытие pytest тестами

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка параметров

Отредактируйте `.env` файл или установите переменные окружения:

```bash
DATA_SOURCE=cps_tiles    # источник данных
USE_FAULTS=False         # использовать ли разломы
BATCH_SIZE=4
LEARNING_RATE=3e-4
```

### Конвертация CPS гридов в PNG тайлы (если используете cps_tiles)

```bash
python data/convert_cps_to_tiles.py
```

Это создаст:
- Полные PNG изображения в `data/images_cps_full/`
- Разбитые на тайлы в `data/images_cps/`

### Проверка на overfit (быстрый тест)

```bash
python run_overfit_check.py
```

### Полное обучение

```bash
python run_training.py
```

### Оценка модели

```bash
python evaluate_model.py
```

## 🔧 Ключевые компоненты

### Модели
- `models/unetplusplus.py` — реализация U-Net++ с глубокой супервизией

### Источники данных

#### cps_tiles
- 5 входных каналов без разломов: RGB(3) + Depth(1) + Isolines(1)
- 6 входных каналов с разломами: + Faults(1)
- Размер тайлов: 448×640
- Данные генерируются из CPS гридов с помощью `utils/cps_utils.py`

- **Важно**: разломы вырезаются на картах rgb, depth_norm и isolines (области разломов становятся черными)

### Losses
- Комбинации BCE, Dice с весами (по умолчанию 0.5/0.5)
- Masked версии для игнорирования фона и областей под разломами

### Метрики
- IoU (Intersection over Union)
- Dice Coefficient
- Precision, Recall, F1-Score
- FP/FN Area (доля ложных срабатываний/пропусков)

### Утилиты
- `utils/cps_utils.py` — чтение CPS гридов, генерация RGB, изолиний, замкнутых контуров
- `utils/dataset_utils.py` — парсинг имен файлов, группировка семплов, загрузка данных
- `data/check_data_leakage.py` — проверка на утечку данных между сплитами
- `training/gradient_tracker.py` — мониторинг градиентов во время обучения
- `training/analyze_anomalies.py` — детектирование аномалий в процессе обучения

## 📊 Формат данных

### Именование файлов

Формат: `{number}_{x|y}_{type}_{name}.png`

Примеры для cps_tiles:
```
001_x_structuralNOisoline_Ach3-2-1_toptop1.png   # RGB карта
001_x_structuralBlackWhite_Ach3-2-1_toptop1.png  # Depth
001_x_isolines_Ach3-2-1_toptop1.png              # Изолинии
001_y_traps_Ach3-2-1_toptop1.png                 # Ловушки (таргет)
```

### Группировка данных

Семпл определяется комбинацией `{number}_{name}`. Разделение на train/val/test происходит по горизонтам (`name`), чтобы избежать утечки данных.
