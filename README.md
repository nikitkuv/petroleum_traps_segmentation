# Petroleum Traps Segmentation

Проект для сегментации структурных ловушек по структурным картам сейсмических горизонтов на основе архитектуры **U-Net++** с использованием **PyTorch**.

## 🎯 Описание

Проект предоставляет полный пайплайн для обучения, оценки и визуализации моделей сегментации структурных ловушек по структурным картам сейсмических горизонтов. Включает в себя продвинутые техники мониторинга градиентов, защиты от утечки данных и детектирования аномалий.

## ✨ Особенности

- **Архитектура**: U-Net++ с поддержкой различных encoder'ов (ResNet34)
- **Источники данных**: 
  - `cps_tiles`: PNG файлы из CPS гридов с каналами RGB, depth, isolines [+ faults опционально]
- **Мониторинг**: Трекинг градиентов (взрыв/затухание), анализ аномалий в лоссах
- **Защита от leakage**: Утилиты для проверки пересечений между train/val/test
- **Гибкость**: Поддержка режимов с разломами и без, кастомные лоссы и метрики
- **Тестирование**: Полное покрытие pytest тестами

## 🔧 Ключевые компоненты

### Модели
- `models/unetplusplus.py` — реализация U-Net++

### Источники данных

#### cps_tiles
- 6 входных каналов без разломов: RGB(3) + Depth(1) + Isolines(1) + MapMask(1)
- 7 входных каналов с разломами: + Faults(1)
- Размер тайлов: 448×640
- Данные генерируются из CPS гридов с помощью `utils/cps_utils.py`

- **Важно**:
  - Разломы вырезаются на картах rgb, depth_norm и isolines (области разломов становятся черными/0)
  - map_mask включает в себя как области за пределами карты, так и области разломов (оба типа заполняются 0)
  - map_mask добавляется как дополнительный входной канал для обучения модели

### Losses
- Комбинации BCE, Dice с весами (по умолчанию 0.5/0.5)
- Masked версии для игнорирования фона и областей под разломами

### Метрики
- IoU (Intersection over Union)
- Dice Coefficient
- Precision, Recall, F1-Score
- FP/FN Area (доля ложных срабатываний/пропусков)

### Утилиты
- `utils/cps_utils.py` — чтение CPS гридов, генерация RGB, изолиний, замкнутых контуров
- `utils/dataset_utils.py` — парсинг имен файлов, группировка семплов, загрузка данных
- `data/check_data_leakage.py` — проверка на утечку данных между сплитами
- `training/gradient_tracker.py` — мониторинг градиентов во время обучения
- `training/analyze_anomalies.py` — детектирование аномалий в процессе обучения

## 📊 Формат данных

### Исходные данные

Изначально имеются CPS гриды:
- **CPS грид карты глубин** — структурная карта глубин
- **CPS грид карты ловушек** — бинарная маска (1 = ловушка, 0 = не ловушка)

### Пайплайн обработки данных (CPS → PNG тайлы)

Пайплайн загрузки и обработки входных данных из CPS гридов:

1. **Загрузка CPS гридов** (больших карт глубин, ловушек и разломов)
2. **Трансформация CPS гридов в изображения**:
   - Карты глубин конвертируются в:
     - `rgb` (PNG) — RGB карта без изолиний (colormap purple_jet)
     - `isolines` (PNG) — бинарная маска с белыми изолиниями
     - `faults` (PNG) — бинарная маска разломов
     - `traps` (PNG) — бинарная маска ловушек (таргет)
   - Карты глубин конвертируются в:
     - `depth_norm` (.npy) — нормализованная карта глубин в черно-белой палитре (сохраняется как float32 массив NumPy)
3. **Ресайз карт разломов**: CPS гриды разломов часто имеют большее разрешение (больше ячеек, меньший размер ячейки), чем структурные карты и карты ловушек, поэтому они ресайзятся до размера структурных карт с использованием интерполяции ближайшего соседа (`cv2.INTER_NEAREST`)
4. **Вырезание невалидных областей**: На картах `rgb`, `depth_norm` и `isolines` значения за пределами карты и в местах разломов заполняются 0 (черный цвет)
5. **Нарезка на тайлы**: Большие изображения нарезаются на тайлы размером 640×448 с overlap и сохраняются в PNG (для depth_norm — в .npy)
6. **Загрузка в dataset**: PNG/.npy тайлы загружаются, карты `rgb` и `depth_norm` нормируются в диапазон [0, 1]
7. **Генерация map_mask**: В dataset автоматически создается маска `map_mask`, где:
   - 1 = валидная область карты
   - 0 = невалидная область (за пределами карты ИЛИ разломы)
   - `map_mask` добавляется как отдельный входной канал модели

### Входные данные (X)

| Канал | Описание | Формат | Нормализация |
|-------|----------|--------|--------------|
| 1. rgb | RGB карта без изолиний | uint8 PNG | [0, 1] |
| 2. depth_norm | Карта глубин в черно-белой палитре | float32 | [0, 1] (0 - низко, 1 - высоко) |
| 3. isolines | Бинарная маска с белыми изолиниями | uint8 PNG | бинарная |
| 4. faults | Бинарная маска разломов (опционально) | uint8 PNG | бинарная (1 - разломы, 0 - фон) |
| 5. map_mask | Бинарная маска валидной области карты | float32 | бинарная (1 - валидная область, 0 - за пределами карты и разломы) |

**Итого входных каналов:**
- Без разломов (`USE_FAULTS=False`): **6 каналов** (RGB(3) + Depth(1) + Isolines(1) + MapMask(1))
- С разломами (`USE_FAULTS=True`): **7 каналов** (RGB(3) + Depth(1) + Isolines(1) + Faults(1) + MapMask(1))

### Целевые данные (Y)

| Канал | Описание | Формат |
|-------|----------|--------|
| traps | Бинарная маска ловушек | бинарная (1 - ловушки, 0 - фон) |

### Именование файлов

Формат: `{number}_{x|y}_{type}_{name}.png`

Примеры для cps_tiles:
```
001_x_structuralNOisoline_Ach3-2-1_toptop1.png   # RGB карта
001_x_structuralBlackWhite_Ach3-2-1_toptop1.npy  # Depth (сохраняется как .npy)
001_x_isolines_Ach3-2-1_toptop1.png              # Изолинии
001_x_faults_Ach3-2-1_toptop1.png                # Разломы (опционально)
001_y_traps_Ach3-2-1_toptop1.png                 # Ловушки (таргет)
```

### Группировка данных

Семпл определяется комбинацией `{number}_{name}`. Разделение на train/val/test происходит по горизонтам (`name`), чтобы избежать утечки данных.
