# Petroleum Traps Segmentation

Проект для сегментации структурных ловушек по структурным картам сейсмических горизонтов на основе архитектуры **U-Net++** с использованием **PyTorch**.

## 🎯 Описание

Проект предоставляет полный пайплайн для обучения, оценки и визуализации моделей сегментации структурных ловушек по структурным картам сейсмических горизонтов. Включает в себя продвинутые техники мониторинга градиентов, защиты от утечки данных и детектирования аномалий.

## ✨ Особенности

- **Архитектура**: U-Net++ с поддержкой различных encoder'ов
- **Мониторинг**: Трекинг градиентов (взрыв/затухание), анализ аномалий в лоссах
- **Защита от leakage**: Утилиты для проверки пересечений между train/val/test
- **Гибкость**: Поддержка режимов с разломами и без, кастомные лоссы и метрики
- **Тестирование**: Полное покрытие pytest тестами

## 🔧 Ключевые компоненты

### Модели
- `models/unetplusplus.py` — реализация U-Net++ с глубокой супервизией

### Losses
- Комбинации BCE, Dice, Focal Loss
- Кастомные лоссы для несбалансированных данных

### Метрики
- IoU (Intersection over Union)
- Dice Coefficient
- Precision, Recall, F1-Score

### Утилиты
- `data/check_data_leakage.py` — проверка на утечку данных между сплитами
- `training/gradient_tracker.py` — мониторинг градиентов во время обучения
- `training/analyze_anomalies.py` — детектирование аномалий в процессе обучения

## 📊 Режимы и форматы данных

Поддерживаются два режима работы:
1. **С разломами** — учитываются разрывные нарушения
2. **Без разломов** — без учета разрывных нарушений

Поддерживаются два формата входных данных:
1. **png** — изображения карт в формате .png
2. **cps** — 2D гриды карт в формате cps
