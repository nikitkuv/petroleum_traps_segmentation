# Эксперименты обучения

## Реализованные эксперименты

### ✅ v1: Канал замкнутых изолиний (closedIsolines)

**Статус**: Реализовано

**Описание**: Добавлен новый канал `closedIsolines`, который содержит маску замкнутых контуров/ловушек.

**Изменения**:
- `utils/cps_utils.py`: Функция генерации замкнутых изолиний через `scipy.ndimage.label`
- `data/dataset.py`: Загрузка нового канала в датасет
- `settings.py`: Увеличено количество входных каналов с 4 до 6 (для png без разломов) или с 5 до 7 (для cps_tiles с разломами)

**Ожидаемые улучшения**:
- Лучшее определение границ ловушек
- Снижение false positives
- Улучшение IoU на 5-10%
