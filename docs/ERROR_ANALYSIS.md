## Обновленная модель с каналом closedIsolines

После добавления канала `closedIsolines` ожидается улучшение по следующим направлениям:

### Улучшения от нового канала

1. **Лучшее определение границ ловушек**: Канал замкнутых изолиний явно указывает на замкнутые контуры
2. **Снижение false positives**: Модель учится отличать замкнутые структуры от незамкнутых
3. **Улучшение IoU**: Более точное соответствие предсказаний и таргетов
